# 技术说明

## 状态与命令

`service.rs` 的后台线程是计时器和偏好的唯一 owner。界面、桌宠和托盘读取不可变快照，操作通过有界队列发送。

成功入队的命令获得递增序号。后台处理成功或失败后都发布确认序号，界面在确认前禁用下一次修改，避免连续操作用旧快照覆盖设置。

## 计时

`focus.rs` 使用单调时钟累计实际专注时长。暂停和进程关闭期间不累计。应用提供本地日期与距离午夜的时长，核心据此分配跨日统计。

专注完成进入休息，休息完成回到空闲。检测到桌面不可访问或长时间调度中断时暂停，等待用户继续。

## 文件

`storage.rs` 验证版本、时长、日期、统计上限和文件大小，再进行原子替换。正常保存前备份上一份有效文件。加载失败时设置写入屏障；不能用默认数据覆盖原统计。

退出先停止接受新命令，处理已经接受的队列，再保存最终快照。失败会报告原因，线程退出有两秒等待上限。

## 窗口与动画

`pet.rs` 使用透明 GPUI 窗口，`ui.rs` 提供控制面板与提醒。关闭面板销毁窗口，后台计时继续，托盘可重新创建窗口。

`sprites.rs` 从 PNG 九宫格读取透明边界，并在内存中对齐角色脚底。图像资源嵌入程序，帧选择由输入活动和计时状态决定。

`windows_input.rs` 只导出活动次数、鼠标坐标和桌面可访问状态。物理按键状态仅短暂用于判断活动，没有保存或传输。

## 检查

`cargo test --locked`、`cargo fmt --check` 和 `cargo clippy --all-targets -- -D warnings` 验证源码。`scripts/smoke.ps1` 创建隔离的近结束会话，检查 Windows 窗口、真实计时、提醒渲染及退出保存。生成的计数报告用于自动检查，不替代人工界面体验。

# 办公桌宠：始终知道下一件事

已确认的方向：宠物下方常驻待办便签，默认展示最多三项；不需要悬停或打开面板才能看到。当前任务突出、截止和逾期清楚、完成可撤销。宠物与便签整体拖动，仅拖动宠物区域，避免勾选时误移窗口。

桌面便签使用清晰的不透明暖白底/深色文字，绿色只强调当前任务。深色主题使用原有系统主题表面。允许手动收起为当前任务摘要、关闭便签；其余任务通过管理面板访问。

管理面板默认今日待办，提供快速新增、优先级、截止时间、完成/撤销和开始专注；设置、统计与数据位置继续保留。昨日未完成任务延续显示，优先级/截止辅助排序，用户选择的当前任务保持突出。

专注与待办关联，但计时结束不自动完成待办；用户勾选才完成。完成时短暂宠物庆祝并提供撤销，避免自动奖励掩盖工作未完成。数据本地原子写入，兼容原 focus.json，并保留已有专注记录。

首版不引入账户、云同步、模型调用或自动抓取办公软件。所有任务文字由用户输入，不生成假待办。建议以后补充每日重复任务、周回顾和工作时间提醒，需要独立验证时区与通知行为。

验证：模型/排序/旧文件迁移/坏文件保护测试；原生构建；独立测试数据目录的任务新增、常驻显示、完成撤销、专注与拖动、重启恢复，不修改用户真实任务数据。
